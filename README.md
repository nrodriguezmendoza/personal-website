# Personal Website

Nathalie Rodriguez's personal website, built with [Next.js](https://nextjs.org).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Other scripts

- `npm run build` — production build
- `npm start` — serve the production build
- `npm run lint` — run ESLint

## Photos

Gallery photos live in `public/images/`. To change them, drop image files there
and update the `PHOTOS` list in `src/app/Gallery.tsx`.
